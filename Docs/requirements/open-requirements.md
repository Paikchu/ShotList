### R-14 · 用户要在多部影片间复用分镜文字格式时，应能预设多份影片模板，新建影片时选用或事后绑定，并在镜头面板里直接选择应用

**验证状态：** 待验证

**代码位置：** 待实现。预计：ShotList/Models/FilmTemplate.swift（新增）· 模板模型；ShotList/Models/Film.swift · `templateID`、`FilmLibrary.templates`；ShotList/Models/ShotStore.swift · 模板增删改、绑定、按模板新建影片、升级迁移；ShotList/Views/FilmTemplateSheet.swift（取代 ShotTemplateSheet.swift）· 模板库页、编辑页、新建影片选模板页；ShotList/Views/FilmBar.swift · `FilmActionDialogs`（「从模板新建」）；ShotList/Views/ClipOptionsSheet.swift · 「应用模板」菜单

**预期结果：** 用户可以提前写好多份命名模板。新建影片时可以选「从模板新建」，新影片直接绑定所选模板；已有影片随时可以在「模板」页改绑另一份或改回默认。写镜头内容时，「应用模板」列出全部模板，点哪份就把哪份应用到内容框，已写的字保留，只补缺的标签行。

**需求详情**

**当前行为：** 模板是影片自带的一段文字（[R-10](delivered-requirements.md#r-10)）：每部影片各写各的，新建影片只能从默认四行起步；想把一部影片写好的格式用到另一部，只能手抄。镜头面板的「应用模板」只能应用当前影片的那一份。

**目标行为：**

1. **模板库。** 模板是应用级的：一份模板 = 名称 + 一段纯文字（形态与 R-10 的模板相同，不含占位符）。分镜页影片菜单的「模板」打开「模板」页（取代 R-10 的单份编辑页），列出「默认」（内置的四行「描述：」「字幕：」「上方角标：」「转场：」，不可编辑、不可删除）与全部自建模板，按创建先后排列。右上角加号新建模板：新模板预填默认四行，进入编辑页；名称可空，空名称显示为「未命名模板」。每份自建模板行尾有「更多」菜单：编辑、复制、删除。编辑页有名称与内容两个输入框，输入自动保存（停手后落盘，离开页面时立即落盘）。新建后一个字没改就离开的模板自动丢弃，不在库里留空壳。
2. **绑定。** 每部影片至多绑定一份模板，未绑定的影片用「默认」。「模板」页的行是单选：点一行把当前影片绑定到它并打勾，点「默认」改回默认；页面标题下写着影片名，看得出绑定的是哪一部。**创建影片之后**随时可以改绑。
3. **新建影片时选用。** 库里至少有一份自建模板时，「新建影片？」对话框（分镜页影片菜单与历史页影片条共用）在「新建」旁多一个「从模板新建」；点它弹出选模板页，点一份模板：新建影片并绑定它，当前影片照常留在影片库。库里没有自建模板时对话框与 [R-5](delivered-requirements.md#r-5) 完全一致。
4. **镜头面板里选择应用。** 内容框下方的「应用模板」：
   - 库里没有自建模板时不变：一个按钮，应用默认（或框里已是默认样子时不出现）；
   - 有自建模板时变成菜单：当前影片绑定的排第一并打勾，其余自建模板按库里顺序，「默认」排最后；点哪一项就把哪一项应用到内容框，应用规则不变（框空则整段填入；框里有字则全部保留，认不出标签的开头文字并进第一个标签，缺的标签补一行）；
   - 某一项应用后内容不会变化就不列出；全部都不会变化时整个入口不出现。
   应用仍是一次性拷贝，改模板不影响已应用的镜头。
5. **删除模板。** 确认对话框写明后果：绑定它的影片改用默认，已应用到镜头里的文字不动。确认后这些影片的绑定清除。
6. **升级旧数据。** R-10 时每部影片的自定义模板文字迁进模板库：有自定义文字的影片各得到一份名为「影片名 模板」的模板并绑定它（文字完全相同的合并为同一份）；没有自定义文字的影片保持未绑定。迁移前先把原 `films.json` 备份为 `films.json.before-templates`（已存在则不覆盖），与 `films.json.before-merge` 同一个保险思路。

**范围：** 影片菜单的「模板」页、新建影片确认对话框、镜头面板（分镜页与历史页共用）、`Film` / `FilmLibrary` 数据与旧数据读取。

**推断（未经用户确认）：**

- 用户原话「用户创建模板的时候可以选择从模板创建」按「创建**影片**的时候可以选择从模板创建」解读。
- 「影片模板」按 R-10 的模板形态解读：模板内容是分镜内容的文字格式，不含剪辑风格，也不预置镜头。想让模板同时带剪辑风格或预置镜头骨架，需要说明。
- 「绑定」按引用解读：影片记住绑定的是哪份模板，改模板后该影片下一次应用拿到的是新内容；删除模板则解除绑定。
- 「过往模板」按整个模板库解读，不只是当前影片绑定的那一份。
- 模板库入口沿用 R-10 的位置（分镜页影片菜单的「模板」），没有另开设置页。
- 「从模板新建」放在既有的「新建影片？」对话框里，而不是另设一个菜单项，以免动摇 R-5 的居中确认。
- 内置「默认」不做成可编辑的库内模板：R-10 已有「把模板清空回退默认」的语义，保留一份不变的基线更稳。

**明确不做：** 不做占位符、变量或自动填值；不做批量套用、「应用到全部镜头」或新建镜头时自动套用；不解析、不校验模板标签；模板不进导出包；不含剪辑风格与预置镜头；不做模板的排序、导入导出与分享；不做历史页里的模板入口（历史页只共用新建影片对话框）。

**对其他功能的影响：**

- R-10 的单份编辑页被模板库页取代；`Film.shotTemplate` 不再写入，读旧数据时迁移（见目标行为 6）。
- `FilmLibrary` 新增 `templates`，与影片、当前影片指针同一份 `films.json` 原子落盘；旧文件缺这个键时按空处理，手写解码兜底。
- 绑定与新建影片算用户编辑，刷新影片 `updatedAt`；编辑模板本身不刷新任何影片的 `updatedAt`。
- 绑定不算「写过内容」：`Film.isBlank` 不看绑定，「从模板新建」后不动它就切走，这部影片照常被当作空壳回收（模板本身留在库里，没有东西丢失）。R-10 里「写过模板的影片不算空壳」随迁移一并取消：迁移后旧的自定义文字已在库里。
- 导出不受影响：模板不进导出包，导出与失效判断都不读模板。

**定级依据：** 定为 P2（用户未指定级别，按规则判定，如需上调请说明）。R-10 已有单份模板可用，本条是多份复用与新建时选用的增强，不阻断从拍摄到导出的主路径。

**验收方法**

1. 前置环境：模拟器安装 Debug 构建，用隔离数据准备三部影片：影片 A 带 R-10 格式的自定义模板文字（`films.json` 里 `shotTemplate` 为「A1:」「A2:」两行）、影片 B 无自定义、影片 C 与 A 同一段自定义文字；影片 A 有 2 个镜头（内容一空一有），库里此时没有 `templates`。
2. 升级：启动应用。`films.json` 里出现 `templates`，只有一份「A 影片名 模板」，A 与 C 的 `templateID` 都指向它，B 没有 `templateID`，所有影片不再写 `shotTemplate`；同目录有 `films.json.before-templates`，内容是升级前原文；再次启动后备份没有被覆盖、模板没有重复。
3. 分镜页（影片 A）影片菜单点「模板」：标题「模板」、副标题是影片 A 的名字；列表是「默认」和那一份迁移来的模板，后者打勾。
4. 点右上角加号：进入编辑页，内容预填默认四行，名称为空；填名称「访谈」、把内容改成「问题：」「回答：」两行；返回列表：多了「访谈」，行内预览显示首行「问题：」，杀掉应用重启后仍在。
5. 加号新建一份，什么都不改就返回：列表里没有多出这份。
6. 绑定：点「访谈」，它打勾、原来那份取消打勾；点「默认」，只有「默认」打勾。`films.json` 里影片 A 的 `templateID` 随之变化，影片 B、C 不受影响。
7. 「访谈」行尾更多菜单：「复制」多出一份同内容的模板；「编辑」进编辑页；「删除」弹确认，正文写明绑定它的影片改用默认；确认后从库中消失，绑定它的影片 `templateID` 清除，已应用到镜头的文字不变。
8. 镜头面板：先把影片 A 绑定到「访谈」。打开内容为空的镜头：「应用模板」是菜单（库里有自建模板），列表第一项是「访谈」并带勾，其后是其他自建模板，最后是「默认」；点「默认」：内容变成默认四行。清空后点「访谈」：内容变成「问题：」「回答：」。打开已有内容「描述：横摇」的镜头：点「访谈」，「描述：横摇」保留，后面补上「问题：」「回答：」；此时列表不再出现「访谈」。内容已经完全是某份模板的样子时，那份不列出；全部模板都不会变化时，「应用模板」整行不出现。改「访谈」的内容后，已应用的镜头不变。
9. 库里没有自建模板（删光后）：镜头面板「应用模板」回到单个按钮，行为与 R-10 一致；影片菜单「新建影片」对话框只有「新建 / 取消」，与 R-5 一致。
10. 新建影片时选用：库里有「访谈」时，分镜页影片菜单点「新建影片」：居中对话框有「新建」「从模板新建」「取消」；点「从模板新建」：弹出选模板页，列出全部自建模板（不含「默认」）；点「访谈」：进入新影片，「模板」页里「访谈」已打勾，影片 A 仍在影片库。历史页影片条的「新建影片」同样有「从模板新建」。选模板页里下滑关闭：不新建影片。
11. 新影片不加任何内容，直接在影片菜单切回影片 A：新影片被当作空壳回收，「访谈」仍在库里。
12. 失败判据：升级后任一影片的自定义模板文字丢失；「应用模板」应用了与所选不同的模板，或覆盖了已写的内容；删除模板后仍有影片绑定着已不存在的模板导致「应用模板」无内容；库里没有自建模板时对话框多出「从模板新建」；新建后没改就返回的模板留在库里；重复启动后模板重复迁移。
